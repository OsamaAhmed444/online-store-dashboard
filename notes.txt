1. API DOCUMENTATION

API URL:
https://e-commerce-api-3wara.vercel.app

Login:
POST /auth/login

Login Body:
{
"email": "[admin@koda.com](mailto:admin@koda.com)",
"password": "ADMIN_PASSWORD"
}

Login Response:

* success
* token
* user

User Data:

* id (_id)
* username
* email
* role
* avatar

Admin Role:
user.role === "admin"

Authentication:

* Token returned in response
* Token also stored as HttpOnly Secure cookie

* GET /auth/me
* GET /auth/admin-test

How the team uses them

For example, a Users page can simply do:

import { getUsers } from "../api/users"

Then call:

getUsers()

The page doesn't need to know the URL, Axios configuration, cookies, or authentication details.

That's the whole point of this API layer:

Frontend Page
     ↓
API Function
     ↓
Shared axios.js
     ↓
Backend API
